## 5. 判定

### 合格 0 — この指標ファミリーの検証を完全終了する

事前に確定した合格条件を満たした候補は **0 / 4** だった。

依頼書に定めたとおり、**以後 Squeeze / WaveTrend / ADX の 3 指標について新しい切り口を試すことはしない。**

これまでの積み上げ:

| フェーズ | 検証内容 | 結果 |
|---|---|---|
| Phase 1 | スクイーズ解放時の `val` の符号（既定パラメータ）| 0 / 18 |
| Phase 1 追試 | 解放定義を原典（黒→灰）に修正 | 完全に同一（青が 0 件）|
| Phase 1b | WaveTrend / ADX 単体（標準設定）| 0 / 36 |
| Phase 1c Part A | 65 設定のグリッド探索 | 候補 4 件を選定（判定なし）|
| **Phase 1c Part B** | **未使用データでの確認** | **0 / 4** |

探索で見つけた「良さそうな設定」は、**未使用期間では再現しなかった**。
これは Part A の数字が実力ではなく、多重比較（1,170 セル）の産物だったことを意味する。


### 言えること / 言えないこと

- 言える: Part A（2025-2026）で選んだ候補が、Part B（2023-2024）でどうなるか。
  **探索と確認でデータを完全に分離してある**ので、この判定は「見かけ上良い設定」を排除できている。
- 言えない: グリッドに入れなかった設定（例: 逆張り、別のシグナル定義、上位足フィルター）については何も言えない。
  ただし結果を見てからそれらを足すのはデータスヌーピングであり、やらない。
- コスト前提は COSTS.md のシナリオ F（Lighter 手数料 0% + 往復 1.0 bps）という**最も甘い前提**である。
  これで落ちるなら、他のどのコスト前提でも落ちる。
